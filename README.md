## 掲載情報

- 宗派・本尊・沿革・参拝時間・住所・電話はこれまで確認した県・市の公開情報に基づくものです。
- 年中行事はユーザー提供情報です。「節分回」「盂蘭盆回」「施餓鬼回」は「会」の表記で掲載しています。
- メールアドレスは未提供です。アドレス確定後にお問い合わせ欄へ `mailto:` リンクを追加できます。
- `<head>` に OGP（og:title など）と schema.org の `BuddhistTemple` 構造化データを記載しています。公開URLが決まったら `og:url`・`og:image`（絶対URL）と `canonical` を追加してください。
- favicon はインライン SVG（輪違モチーフ）です。正式なロゴが決まれば差し替えてください。

## 動作

- 起動時はディープブルーのローディング画面。中央に自作SVGの輪違モチーフを描画し、TOP写真の読み込み・デコードとフォント準備後にフェードアウト。それからTOP・本文の演出を開始します。正式な寺紋の原稿ではなく、ご指定の二つの輪を組み合わせたデザインです。
- 通常の最短表示は1.5秒。準備待ちは最大4.5秒、主JSの読み込み失敗時も独立した6秒の安全タイマーで解除。「スキップして表示」またはEscですぐに本文へ進めます。動きを減らす設定では最短表示待ちとフェードを省略し、JavaScript無効時はローディング自体を表示しません。
- PCは常時表示の追尾メニュー、850px以下はハンバーガーメニュー。全画面メニューは閉じるボタン・Esc・項目選択で閉じます。
- 実際のヘッダー高を測定し、本文やアンカー先との重なりを防止。
- ページ全体のスクロール表示、写真のホバー拡大、閲覧進捗と現在地表示。
- 動きを減らすOS設定に対応。JavaScriptが無効でも全本文が表示されます。
- 寒川神社サイト（https://samukawajinjya.jp/）の霞・文字のにじみ・場面転換を参考に実装。参考サイトの画像・動画・スクリプトは流用していません。
- 見出しは一文字ずつ分割せず、意味のまとまりを保った行単位で表示。歴史の見出しは「このまちと、時を重ねて。」に変更。
- TOP写真はマウスでなぞると水面のように波紋が広がります。ポインターの軌跡が水面の高さとして伝わり、その傾きを光として写真に重ねています。指を止めると約2.6秒で自然に静まります。クリックで一度だけ大きく波打ちます。
- 波紋はTOP写真のみ。マウス等の細かいポインターがある端末だけで動作し、スマートフォン・タブレットでは生成しません。「演出を止める」と動きを減らすOS設定では水面を消去し、入力も受け付けません。画面外・別タブへ移動した際も停止します。
- 写真は水中から浮かび上がる演出（SVGの揺らぎ、ぼかし、浮上、水面の光）。約3秒で鮮明になり、終了・停止時には揺らぎ用フィルターを破棄。写真の枠とキャプションは動きません。
- TOPの「演出を止める」で霞・スクロール連動・実行中の表示演出を停止できます。文字は演出にかかわらず表示されます。
